# Changelog

## 2.0.0 — 2026-11-02

This polished 2.0.0 release is built from the legacy V2–V8 development snapshots. Those filenames describe development iterations. The original `MSO-V8.py` remains unchanged.

- Refreshed the desktop interface with consistent colours, spacing, typography and branding.
- Grouped folder selection, metadata options and transfer settings into a clearer workflow.
- Polished the preview, episode resolver, progress feedback and activity log.
- Corrected resource discovery for the included logos and application icon.
- Unified the displayed application version and release entry point.
- Added installation instructions, dependency manifests, a Windows build configuration and automated checks.
- Prepared clean source contents that exclude local settings, credentials, logs and recovery records.

The release retains TheTVDB and TMDB support, dry runs, review and approval, Move/Copy operations, verification choices, cancellation, NFO sidecars, portable credential storage and Undo.
