# MetaSeries Organiser 2.0.0 for Windows

Extract the complete ZIP, then open **MetaSeries-Organiser.exe**. Python does not need to be installed separately.

Keep the `_internal` folder beside the executable. You can place the extracted application folder wherever you want to run it.

Start with **Preview only** to review the proposed filenames. Enter your own TMDB or TheTVDB credentials in **Connections & settings** when using online matching.
